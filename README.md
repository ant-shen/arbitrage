# Sports Betting Arbitrage Finder

This application helps you find arbitrage opportunities across different sports betting platforms. It calculates potential profits and provides a user-friendly interface to view and analyze betting opportunities.

## Features

- Real-time odds fetching from multiple bookmakers
- Arbitrage opportunity detection
- Profit calculator
- Web interface for easy access
- Support for multiple sports and betting types

## Setup

1. Clone this repository
2. Install dependencies:
```bash
pip install -r requirements.txt
```
3. Create a `.env` file with your API keys (if required)
4. Run the application:
```bash
python app.py
```

## Usage

1. Open your web browser and navigate to `http://localhost:5000`
2. Select the sport and event you're interested in
3. View available arbitrage opportunities
4. Use the calculator to determine optimal bet amounts
